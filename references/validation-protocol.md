# 自我验证协议（11 条断言验算标准）

每输出一个 Step 之前，先在内部完成该步的断言验算。**不允许跳过，不允许"感觉差不多"。**

## 验算执行流程

```
1. 定位当前 Step 对应的验证条目（下表）
2. 逐条判定 Pass / Fail，并在脑中给出判定依据
3. 出现任意 Fail → 针对失败项重写该部分 → 重新验算 → retry_count += 1
4. retry_count >= 5 仍不全 Pass → 停止静默重试，向用户显式说明：
   - 卡在第几条
   - 为什么无法在该条上达标（信息缺失 / 主题本身有争议 / 需要用户补充材料）
   - 当前最优解是什么
   - 需要用户做什么才能补齐
5. 全 Pass → 呈现内容（可在结尾标注"自检已通过（N/N）"）
```

## 逐条标准

### 断言 1（Step 1）：专家匹配度与坑点含金量

| 验证问题 | 合格标准 | 不合格特征（判 Fail） |
|---|---|---|
| 专家是否匹配主题类型？ | 角色与主题的学科/行业同源，且已按主题做过改写 | 套用通用名、与主题无关 |
| 是否有 4-5 个且互相冲突/互补？ | 至少一对视角观点相左 | 5 个视角说法雷同 |
| 坑点是否具体？ | 含具体场景 + 具体后果 + 可操作规避动作 | "要多练习""打好基础""保持热情" |
| 是否有辨伪视角？ | 至少 1 个视角教如何辨别真假高手 | 全部视角都在讲"怎么学" |

### 断言 2（Step 2）：矛盾有支撑、盲区真实

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 争议是否真实？ | 能说出对立双方是谁、各自依据 | 凭空编造"有人说 A 有人说 B" |
| 是否标注证据强弱与来源类型？ | 每条有强/中/弱 + 来源类型 | 只说"有争议" |
| 是否有适用边界？ | 明确"什么情况下 A 对、什么情况下 B 对" | 只列争议不给判断 |
| 盲区是否切中初学者真实痛点？ | 盲区是新手实操中真实会犯的错 | 写成"不够努力""不重视" |
| 每条盲区是否有 30 秒自检方法？ | 给一个可自测的问题 | 只有描述没有自检 |

### 断言 3（Step 3）：讲稿可讲完、行动可执行

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 讲稿是否在 200-300 字？ | 默读计时 ≤60 秒 | 超过 400 字或少于 150 字 |
| 是否有 5 条铁律且含否定边界？ | 祈使句，每条含"不要…" | 只有正面口号 |
| 今日切入点能否 30 分钟内完成？ | 有具体动作 + 可见完成标志 | "先了解概念""想一想目标" |
| 是否真的今天就能开始？ | 不需要额外采购/等待/审批 | 需要买设备、等账号 |

### 断言 4（Step 4）：评分有依据、验证路径可达

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否覆盖 ≥5 条关键论断？ | 覆盖 Step 1-3 的核心结论 | 只评 1-2 条 |
| 靠谱度是否有打分理由？ | 每条写明依据类型 | 只给数字 |
| ≤3 分项是否给具体一手路径？ | 具体到文档编号/章节/数据库表名/仓库文件 | "可以上网查""参考相关资料" |
| 验证任务是否今天可完成？ | 每条 ≤10 分钟且写明"看到什么算成功/证伪" | 无判定标准 |

### 断言 5（Step 5）：资料权威、比例达标

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 资料数量 3-5 个且权威？ | 官方/标准/经典优先 | 全是营销号文章 |
| 是否指定精读范围？ | 精确到章/节/案例 | "通读全书""看完整套课程" |
| 2:8 比例是否成立？ | 理论 ≈20%，实践 ≈80%，有数值校验 | 理论占一半 |
| 每天是否有降级方案？ | 每天一行"卡住怎么办" | 无降级 |

### 断言 6（Step 6）：每级可检测

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否 5 级递进？ | 复刻→变形→排错→决策→交付 | 难度不分或乱序 |
| 达标标准是否客观？ | 第三方可判定（用例数/指标/清单项） | "感觉掌握了""比较熟练" |
| 每级是否有微实践交付物？ | 实体产物（文件/链接/截图/数据） | "理解原理" |
| 是否有踩坑预警？ | 每级 1-2 条具体坑 | 空着或泛泛而谈 |

### 断言 7（Step 7）：SOP 可照做

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否有准备工作清单？ | 环境/账号/素材 + 前置检查项 | 直接开始 Step 1 |
| 每步是否有成功标志 DoD？ | 可勾选、可观察 | 无标志 |
| 是否覆盖失败/卡住？ | 每步有"失败了怎么办" | 只有 happy path |
| 是否有防重触发与回滚？ | 说明重复执行后果 + 撤销方式 | 无 |
| 是否有 AI 诊断入口？ | 明确让用户提交什么 | 无 |

### 断言 8（Step 8）：题目真实、判定严密

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否单题过关制？ | 一次一题，通过才 +1 | 一次甩 10 题 |
| 场景是否真实？ | 报错日志/事故/突发/两难 | 概念默写、名词解释 |
| 评分点是否唯一或明确？ | 列出 2-3 个可判定的点 | 模棱两可、怎么答都算对 |
| 答错是否讲透并出变式题？ | 点破错因 + 讲透 + 同考点新场景 | 直接给答案跳过 |
| 10 题是否覆盖 5 个等级？ | 每级 2 题 | 集中在某一级 |

### 断言 9（Step 9）：追问直击底层

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否扮演 12 岁小孩？ | 口语、天真、不懂术语 | 仍用导师口吻 |
| 一次是否只问 1-2 个问题？ | 分批追问 | 一次甩 5 个问题 |
| 是否追问"为什么"和类比？ | 至少用到"为什么/打个比方/换个说法" | 只问"还有吗" |
| 是否检查术语依赖？ | 明确指出哪个词没解释 | 放过术语 |
| 通过标准是否明确？ | 连续 2 轮无术语答对 → 通过 | 无判定 |

### 断言 10（Step 10）：速查表可武装到牙齿

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否表格化、高可读？ | Markdown 表格为主 | 大段散文 |
| 报错条目 ≥8 条且有排查顺序？ | 现象→原因→排查顺序→解法 | 只给解法 |
| 核心概念 ≥5 个且有白话解释？ | 12 岁能懂 | 术语解释术语 |
| 是否写成文件交付？ | 落盘 .md 并交付 | 只在对话里贴 |

### 断言 11（Step 11）：闪卡达标

| 验证问题 | 合格标准 | 不合格特征 |
|---|---|---|
| 是否严格 15 张？ | 15 张，不多不少 | 10 张或 20 张 |
| 每张是否有场景问题（不是标题）？ | 以问题形式呈现 | 只写概念名 |
| 是否有白话答案 + 口诀 + 易混点 + 复习节点？ | 五要素齐全 | 缺要素 |
| 复习表是否 1-3-7-15-30？ | 5 个批次 | 缺批次 |
| 是否给出具体日期？ | 依据当前日期推算 | 只写 Day 1 |

## 通用断言（每一步都要过）

| 验证问题 | 合格标准 |
|---|---|
| 是否只输出了一个 Step？ | 没有夹带下一步内容 |
| 是否回答了用户当轮的真实问题？ | 未顾左右而言他 |
| 是否存在自相矛盾？ | 与前面已确认的 Step 内容一致 |
| 是否可落地？ | 每条建议都有具体动作，非套话 |
| 是否有风险提示与备用方案？ | 至少 1 处"如果卡住/失败怎么办" |
| 结尾是否有明确的下一步召唤语？ | 有 👉 【请回复】行 |

## 重试与降级规则

| 重试次数 | 动作 |
|---|---|
| 1-2 | 针对 Fail 项局部重写 |
| 3-4 | 换一个切入角度整体重写该 Step |
| 5 | 停止重试，向用户透明说明卡点 + 给出当前最优解 + 明确需要用户补充什么 |

**显式说明模板（第 5 次仍失败时）**：

```markdown
⚠️ 质量自检未完全通过（Step N，第 5 次尝试）

- 卡住的条目：断言 X —— <具体描述>
- 原因：<信息缺失 / 主题存在真实争议 / 需要你补充材料 / 我的能力边界>
- 当前最优解：下面这版内容，在 <某条> 上打了折扣，折扣点是 <什么>
- 需要你做的：<具体动作，例如"把你现有的环境版本告诉我">
```
